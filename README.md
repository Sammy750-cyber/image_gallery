# Image Gallery

Welcome to the **Image Gallery** project! This repository is a simple and elegant image gallery application built using **HTML**, **CSS**, and **JavaScript**. It provides a platform to display images in a visually appealing and responsive layout.

---

Checkout the project: [Link](https://image-gallery-chi-red.vercel.app/)

---

## Features

- Responsive design for optimal viewing on various devices.
- Organized and visually appealing image layout.
- Lightweight and fast-loading pages.
- Easy to customize and extend.

---

## Technologies Used

This project leverages the following technologies:

- **HTML (36.4%)**: The backbone for structuring the webpage.
- **CSS (49%)**: For styling and making the gallery visually appealing.
- **JavaScript (14.6%)**: Adds interactivity and dynamic behavior.

---

## Setup Instructions

To get started, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sammy750-cyber/image_gallery.git
   
2. Navigate to the project directory:
   ```bash
   cd image_gallery
   
3. Open the <mark>index.html</mark> file in modern web browser to view the gallery.

---

## Usage
- Add your images to the designated folder (e.g., <mark>assets/images</mark>).
- Update the HTML file with the new image paths.
- Customize the CSS styles to fit your needs.
